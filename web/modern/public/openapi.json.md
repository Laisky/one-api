# Laisky One API OpenAPI

The machine-readable OpenAPI 3.1 document is available at:

- [https://oneapi.laisky.com/openapi.json](https://oneapi.laisky.com/openapi.json)
- [https://oneapi.laisky.com/swagger.json](https://oneapi.laisky.com/swagger.json)

Primary operation groups:

- Chat Completions: `POST /v1/chat/completions`
- Responses: `POST /v1/responses`
- Claude Messages: `POST /v1/messages`
- Models: `GET /v1/models`
- MCP: `POST /mcp`

Use `Authorization: Bearer <relay-api-key>` for authenticated relay calls.
