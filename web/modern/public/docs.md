# One API Documentation

Use these machine-readable and human-readable entry points:

- `/llms.txt` for concise agent instructions.
- `/api.md` for endpoint summaries.
- `/auth.md` for authentication guidance.
- `/pricing.md` for quota and billing semantics.
- `/openapi.json` for OpenAPI schemas.
- `/.well-known/api-catalog` for API discovery.
- `/.well-known/agent-card.json` for agent card metadata.
