One API

One API is an agent-friendly AI gateway for developers and autonomous tools. It exposes OpenAI Chat Completions, OpenAI Responses, Claude Messages, embeddings, image, audio, rerank, realtime, video, and MCP proxy endpoints through one operational control plane.

Agent entry points

  • /llms.txt - concise instructions for LLMs and agents.
  • /openapi.json - machine-readable API surface.
  • /.well-known/api-catalog - API catalog linkset.
  • /agents.md - task guidance for coding and integration agents.
