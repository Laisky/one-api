# Provider model research — 2026-09-24

The provider findings below are research notes, not a build or generation stage.
Production defaults are maintained directly in Go; see relay/adaptor/MODELS.md.
The complete prior source archives, converter, and reports remain in Git history.
No JSON catalog, runtime overlay, source lock, or regeneration command is required.
