# OpenAI catalogue refresh — 2026-10-13

Research was performed on October 13 in America/Toronto, crossing into October 14
UTC. The October 14 deprecation notice was already published when inspected.
The implementation baseline is `eed2a6d02e5392f24197f49a70af3ba2ba22f212`.

## Implemented changes

Add only four exact snapshots published on their model cards:

| Published ID | Configuration source |
| --- | --- |
| `gpt-5.4-pro-2026-03-05` | Corrected GPT-5.4 Pro configuration |
| `gpt-5.5-pro-2026-04-23` | Corrected GPT-5.5 Pro configuration |
| `gpt-4o-mini-transcribe-2025-03-20` | Existing GPT-4o Mini Transcribe tariff and limits |
| `gpt-4o-mini-transcribe-2025-12-15` | Existing GPT-4o Mini Transcribe tariff and limits |

GPT-5.4 Pro and GPT-5.5 Pro accept `medium`, `high`, and `xhigh`, not the
complete non-Pro effort ladder. Their defaults are `medium` and `high`,
respectively. Updating these fields corrects the existing request normalizer's
behavior for absent and unsupported efforts. GPT-5.4 Pro's model card explicitly
marks structured outputs unsupported, so that feature is no longer advertised.
The existing Responses routing is retained for both base IDs and snapshots.

`chat-latest` is a rolling alias for ChatGPT's latest Instant model, not a pinned
GPT-5.5 release. Its October 7 refresh is recorded and its documented web-search
capability is included. Its 400,000-token context, 128,000-token output limit and
USD 5.00 / 0.50 / 30.00 input / cached-input / output rates per million tokens
are unchanged. Do not infer another family's long-context surcharge for it.

Lifecycle descriptions record exact published shutdown dates and migration
suggestions. Already-retired IDs remain in the catalogue to preserve existing
configuration and historical pricing. Future notices do not remove models early.
Dates are not extrapolated from snapshots to every family alias. Transcription
format warnings remain intact, and TTS-to-Realtime guidance explicitly warns
that this is not a drop-in `/audio/speech` replacement.

The official deprecation page lists conflicting March 26 and October 23 dates
for `gpt-4-1106-preview`. This patch deliberately leaves that entry unannotated
rather than resolving the conflict by inventing an availability guarantee.

## Pricing and compatibility

All existing numeric prices, context/output bounds and tier thresholds are
preserved. The following Standard GPT-6 prices were rechecked against the pricing
page; each row is USD per million tokens before regional/service-tier adjustments.

| Model | Input | Cached input | Cache write | Output |
| --- | ---: | ---: | ---: | ---: |
| `gpt-6-astra` | 10.00 | 1.00 | 12.50 | 50.00 |
| `gpt-6.1-sol` | 2.00 | 0.10 | 2.50 | 10.00 |
| `gpt-6-sol` | 2.00 | 0.20 | 2.50 | 10.00 |
| `gpt-6-luna` | 0.10 | 0.01 | 0.125 | 0.50 |

The existing input-only boundary above 272,000 tokens remains unchanged. For the
new Pro snapshots it selects USD 60 input / 270 output instead of 30 / 180 for
the entire request. Snapshot configuration is deeply cloned, including mutable
slices and nested audio/pricing settings, so changes cannot leak between IDs.

The GPT-5.6 Cyber card explicitly documents its long-context surcharge; a dash
in the central pricing table is not treated as evidence to remove that tier.
Existing GPT-5.6 Sol promotional pricing is retained without inventing an expiry.
No operator overrides, channel mappings, credentials, schemas or production
workflows change. Azure/AIProxy still inherit the existing compatibility defaults;
these are not independently verified regional or reseller tariffs. Unrelated
hosted-provider catalogues are not populated with native OpenAI snapshot IDs.

## Deliberate exclusions

This is a bounded catalogue correction, not live certification of every historical
row, endpoint, account entitlement, or media billing path.

- Ultrafast is a `service_tier` selection, not a new `gpt-6.1-sol-ultrafast` ID.
  No new tier billing or regional premium is silently enabled by this patch.
- Decisions is a separate API surface using an existing model ID. GPT-Live has
  session-duration charges plus delegated model/tool usage. Both require separate
  transport and metering qualification, not only a catalogue entry.
- Rosalind research/discovery have published prices and access restrictions, but
  their complete model-card contracts could not be retrieved in this audit.
  No context window, output limit, effort ladder or transport support is guessed.
- OpenRouter's Pro aliases are not native OpenAI model IDs. No dated GPT-6.1 Sol
  or GPT-5.3 Codex snapshot is inferred from an announcement date.

## Verification

The new tests exercise real request transformation for Chat Completions, Claude
Messages and Responses entry modes; exact discovery; audio endpoint selection;
pricing resolution on both sides of 272,000 input tokens; full-catalogue tariff
preservation; lifecycle integrity; idempotence; and independent snapshot ownership.
The behavior test file can also run on the unmodified baseline to reproduce the
missing entries and incorrect normalization before the production changes.

Run with Go 1.27.2:

```sh
go test -race -count=1 -p 2 ./relay/adaptor/openai ./relay/adaptor/aiproxy \
  ./relay/adaptor/openrouter ./relay/adaptor ./relay/pricing
go vet ./...
make test-quick
```

Executed results and exact commit identities are recorded in the PR and Actions
receipts. Commands here are not a claim that full database, frontend or live
provider qualification ran. No paid provider request is required by the new tests.
