# OpenAI model update — 2026-09-30

## Verified addition

Add only the published `gpt-6.1-sol` ID. Do not invent a dated snapshot, a
`gpt-6.1` alias, or an account-availability guarantee.

The model has a 1,050,000-token context window, a 128,000-token output limit,
text/image input, and text output. It supports streaming, structured outputs,
and function calling. Tool calling requires Responses; Chat Completions supports
requests without tools. The existing OpenAI adaptor already chooses Responses
for normalized Chat Completions and Claude Messages requests for this model.

### Standard pricing

All amounts are USD per one million tokens, before service-tier or regional
adjustments. Values use the repository's existing `ratio.MilliTokensUsd` unit.

| Input tokens | Input | Cached input | Cache write | Output |
| --- | ---: | ---: | ---: | ---: |
| Up to and including 272,000 | 2.00 | 0.10 | 2.50 | 10.00 |
| More than 272,000 | 4.00 | 0.20 | 5.00 | 15.00 |

The higher tier applies to the **entire request**, not only the excess input.
The input threshold is stored as `272_001`; output tokens must not trigger it.
Cached input is 5% of the input rate, not GPT-6 Sol's 10% rate.
Cache-write pricing uses the existing `CacheWrite5mRatio` billing field, following
the other GPT-6 entries; this change does not define a cache TTL or add a new
cache-control request parameter. No one-hour cache-write price is inferred.

### Reasoning and compatibility

Allowed efforts are `low`, `medium`, `high`, `xhigh`, and `max`, with `medium`
as the default. Neither `none` nor `minimal` is supported. The existing typed
request normalizer maps unsupported efforts to the model default; the new
metadata makes it preserve `xhigh` and `max` rather than falling back to medium.
The raw sampling sanitizer only removes unsupported fields; it does not validate
or rewrite the caller's reasoning effort.

Sampling cleanup must remove `temperature`, `top_p`, `logprobs`, `top_logprobs`,
and the `message.output_text.logprobs` include entry when applicable. It must
preserve tools, encrypted reasoning continuation, and unknown raw JSON values.

## Scope and unchanged behavior

This document describes the native GPT-6.1 Sol addition, not a claim that every
historical OpenAI row has been re-audited. The expanded provider audit and its
unresolved items are in [GPT_PROVIDER_AUDIT_20260930.md](../GPT_PROVIDER_AUDIT_20260930.md). GPT-6 Astra, GPT-6 Sol, and GPT-6 Luna
retain their existing prices, effort ladders, and IDs. No channel configuration,
model mapping, custom price, transport fallback, or tooling tariff is migrated.
OpenRouter now has independently researched Sol 6.1 and Pro definitions; its
IDs and inclusive tier boundary are not copied into the native OpenAI catalog.
Azure routing now selects Responses for the four published GPT-6 IDs. Azure and
AIProxy retain the existing native-pricing fallback; this is not a verified
reseller tariff or evidence of account-specific deployment availability.

OpenAI's deprecation page also reports the Videos API/Sora shutdown on
2026-09-24 and the legacy Completions model shutdown on 2026-09-28. Those are
lifecycle changes, not new model aliases. This patch does not remove historical
pricing entries or silently reset configured channels. Retirement filtering and
migration need a separate lifecycle policy; the model list is not a live
availability probe.

## Regression coverage

`adaptor_gpt61_sol_test.go` covers public discovery, prices, modalities, effort
normalization, mapped-model behavior, endpoint selection for all three normalized
request formats, and third-party catalog isolation.

`gpt61_sol_pricing_test.go` exercises the real pricing resolver at 271,999,
272,000, and 272,001 input tokens, along with empty and large usage. It checks
input, cache-hit, cache-write, output rates, and non-mutation of defaults.

`gpt61_sol_sampling_test.go` covers raw Chat/Responses parameter cleanup, native
Responses serialization, and Chat-to-Responses function-call conversion. It
checks preservation of encrypted reasoning, tools, and large unknown JSON numbers.

Run with the repository's Go 1.27.1 toolchain:

```sh
go test -race ./relay/adaptor/openai -run 'TestGPT61Sol' -count=1
go test -race ./relay/adaptor/... ./relay/pricing/...
go vet ./...
go test -race ./...
make build-frontend-modern
```

These tests use local fixtures and do not require an OpenAI key. They do not
replace a live, account-specific upstream availability test.
